# 💛 반말방 게임 시리즈

카카오톡 오픈채팅방(수도권 30대 직장인 반말방) 3일치 대화 로그(2026-09-20~23)를 바탕으로 만든 게임 모음입니다.

## 게임 목록

### 1탄 — 💛 반말방 퀴즈 (`index.html`)
- 문제 40개 — 상위 10명 멤버 × 4문제 (💬 실제 발언 / 🎬 에피소드 / 🔁 말버릇 / 📌 TMI)
- 인물 도감(10명 프로필 카드), 결과 등급, 연속 정답 스트릭

### 2탄 — 💘 반말방 이상형 월드컵 (`worldcup.html`)
- 이름을 숨기고 실제 발언 카드만 보고 고르는 블라인드 8강 토너먼트
- 멤버당 5~6장의 에피소드 카드 (총 59장, 전부 실제 대화에서 검증)
- 결과: 내 이상형 + 아쉬운 2위 + 궁합 퍼센트 + 방 공유용 복사 버튼

### 3탄 — 😈 반말방 밸런스 게임 (`balance.html`)
- 방 밈 기반 극단의 양자택일 20문제
- 멤버 10명이 사전 투표한 결과 공개 — 내 선택과 방의 선택 비교 (다수파😎 / 소수파😈 / 반반⚖️ 판정)
- 선택마다 내 편/반대편 멤버들의 캐릭터 반응 멘트 (플레이 중엔 익명 🤫, 결과에서 정체 공개)
- 결과: 나와 가장 선택이 비슷한 멤버 "당신은 ○○파!" 랭킹 + 소수선택 칭호

### 4탄 — 🧬 반말방 MBTI (`mbti.html`)
- 방 행동 패턴 4축(벙주O/벙객J, 볼룸파V/텍스트파T, 드립공격수D/리액션부자R, 야행성N/주간형M) × 12문항
- 16가지 방 전용 타입 (🔥심야 벙 사령관, 🍿볼룸 구경단장, 😆낮의 자체 웃음벨...)
- 소울메이트 매칭: 멤버 10명의 실제 답안지와 내 답안지를 비교해 가장 비슷한 멤버 + 환상의 궁합/극과 극 상극
- ※ 원본 채팅 발언 인용 없이 전부 새로 쓴 문항/설명

모든 인용문은 실제 대화 로그에서 검증된 발언만 사용합니다. (4탄 MBTI는 원문 인용 없음)

## 파일

- `index.html`, `worldcup.html`, `balance.html`, `mbti.html` — 게임 본체 (데이터 내장 단일 파일)
- `*.template.html` + `build_*.py` + `*_data.json` — 재생성 파이프라인
- `verify.js`, `verify_worldcup.js`, `verify_balance.js`, `verify_mbti.js` — Playwright 전체 플로우 자동 검증

## 검증

- Playwright 실제 브라우저로 네 게임 전체 플로우 자동 검증 (JS 에러 0)
- 멤버 10명의 실제 채팅 로그 기반 페르소나 에이전트가 블라인드 플레이 + 카드 원문 대조 → 불공정 문항/사실 오류 수정 후 전원 통과
- 밸런스 게임: 페르소나 10명이 20문제 전부 실제 투표 + 반응 멘트 작성, 부적절 문항 2개 교체 후 재투표
- MBTI: 페르소나 10명이 2라운드 응답 (1차 셀프매칭 5/10 → V/D/N축 문항 9개 수정 → 2차 재투표로 답안지 10개 전부 고유 확보, 셀프매칭 거리 0 보장)
